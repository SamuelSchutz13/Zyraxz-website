FoculessYT

Downloads do YouTube sem anúncios, sem rastreio e sem cadastro: cole o link e baixe o MP4 ou o MP3.YouTube downloads with no ads, no tracking and no sign-up: paste the link, get the MP4 or the MP3.

O que fazWhat it does

  • Vídeo MP4 em 1080p, 720p, 480p ou 360p, em H.264/AAC para abrir em qualquer player, ou na melhor qualidade disponível (até 4K).
  • MP4 video at 1080p, 720p, 480p or 360p, in H.264/AAC so any player opens it, or the best available quality (up to 4K).
  • Áudio MP3 na melhor qualidade.
  • MP3 audio at the best quality.
  • Arquivo com o nome do vídeo, acentos e emoji incluídos.
  • File named after the video, accents and emoji included.
  • Links do YouTube, youtu.be, YouTube Music e Shorts.
  • Links from YouTube, youtu.be, YouTube Music and Shorts.
  • Site em português e inglês, temas claro e escuro, e progresso do download.
  • Website in Portuguese and English, light and dark themes, and download progress.

Como funcionaHow it works

Usa o yt-dlp, a única ferramenta que acompanha as mudanças do YouTube, com 4 fragmentos em paralelo. Só links do YouTube chegam a ele, e ele roda sem shell, então a API não vira um baixador genérico.It uses yt-dlp, the only tool that keeps up with YouTube's changes, with 4 parallel fragments. Only YouTube links reach it, and it runs without a shell, so the API never becomes a generic downloader.

Os vídeos nunca ficam guardados. Cada download vai para uma pasta temporária, é enviado para você e apagado assim que a resposta termina.Videos are never kept. Each download goes to a temporary folder, is streamed to you and deleted as soon as the response ends.

Como rodarRun it

cd FoculessYT

# terminal 1: API (http://localhost:3000, docs em /docs)# terminal 1: API (http://localhost:3000, docs at /docs)

npm run start:dev

# terminal 2: site (http://localhost:5173)# terminal 2: website (http://localhost:5173)
cd web
npm install
