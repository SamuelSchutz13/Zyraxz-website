Restyx

Cliente de API REST no navegador: coleções, ambientes com segredos, histórico e exportação. Roda na sua máquina, sem contas, telemetria ou IA.A REST API client in your browser: collections, environments with secrets, history and export. Runs on your machine, without accounts, telemetry or AI.

0

Ver no GitHubView on GitHub

O que fazWhat it does

  • Requisições: método, URL, parâmetros, cabeçalhos e corpo, salvos numa coleção. A resposta mostra status, tempo, tamanho e o corpo destacado.
  • Requests: method, URL, params, headers and body, saved in a collection. The response shows status, time, size and a highlighted body.
  • Ambientes com {{variáveis}}. Variáveis secretas ficam fora do projeto e nunca voltam ao navegador.
  • Environments with {{variables}}. Secret variables live outside the project and never go back to the browser.
  • Histórico da sessão, só em memória e apagado quando o Restyx para.
  • History of the session, in memory only and erased when Restyx stops.
  • Exportação da coleção em JSON ou comandos cURL, sem os segredos.
  • Export the collection as JSON or cURL commands, without secrets.
  • Segurança a sério: CSP estrita, proteção contra DNS rebinding e CSRF, redirecionamentos que descartam credenciais.
  • Serious security: strict CSP, DNS rebinding and CSRF protection, redirects that drop credentials.

Como funcionaHow it works

Um comando, restyx, sobe o servidor e abre o navegador. A coleção fica em .restyx.json na pasta do projeto, sem segredos, então pode ir para o Git.One command, restyx, starts the server and opens the browser. The collection is saved in .restyx.json in the project folder, with no secrets, so it can be committed.

Nada sai da sua máquina além das requisições que você envia. O servidor escuta só em 127.0.0.1, a página exige um token aleatório e não há telemetria, conta, CDN ou fonte remota.Nothing leaves your machine except the requests you send. The server listens on 127.0.0.1 only, the page needs a random token, and there is no telemetry, account, CDN or remote font.

Como rodarRun it

git clone https://github.com/SamuelSchutz13/Restyx.git
cd Restyx
npm install
npm run build
npm link          # deixa o comando `restyx` disponível em qualquer lugar# makes the `restyx` command available everywhere

restyx                          # sobe o servidor e abre o navegador# starts the server and opens the browser
restyx --port 8080 --open=false
